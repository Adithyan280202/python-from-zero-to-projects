# Module 18 -- Practical Python Projects

Use this module to combine concepts from earlier lessons. Build each
project in small steps, test it and document it.

## Beginner projects

### 1. Simple calculator

Ask for two numbers and an operation, then display the result.
**Concepts:** input, conversion, operators and conditions.

### 2. Number guessing game

Generate a secret number and let the player guess, giving higher/lower
hints. **Concepts:** `random`, loops, conditions and input validation.

### 3. Quiz application

Ask questions, check answers and calculate a score. **Concepts:** lists,
dictionaries, loops and conditions.

## Intermediate projects

### 4. Personal expense tracker

Add income and expenses, list transactions and calculate a balance.
**Concepts:** functions, data structures, file handling and JSON.

### 5. To-do list manager

Add, view, complete and delete tasks, then save them between runs.
**Concepts:** functions, data structures, JSON and exceptions.

### 6. Library management system

Add books, list and search books, and track borrowing. **Concepts:**
classes, objects, functions and file storage.

## Advanced projects

### 7. Inventory management system

Add products, update stock, search items and identify low stock.
**Concepts:** OOP, dictionaries, JSON and validation.

### 8. Banking transaction simulator

Create sample accounts, deposit, withdraw and view transaction history.
**Concepts:** OOP, exceptions, file handling and testing.

**Safety note:** This is an educational simulator, not a system for real
money or customer data.

## Project workflow

1.  Write the problem statement.
2.  List required features.
3.  Plan the program flow.
4.  Build one feature at a time.
5.  Test normal and invalid inputs.
6.  Write a README with setup steps and examples.
7.  Commit and push the project to GitHub.
