# Mini Project 06: Student Record Organizer

## 1. Project Overview

The Student Record Organizer is a beginner-friendly Python project that collects and organizes information about three students using Python's built-in data structures.

The program stores student names in a list, roll numbers in a tuple, unique marks in a set, and complete student information in a dictionary.

It also calculates the total and average marks of the students.

## 2. Learning Objectives

By completing this project, you will learn:

- How to create and use lists.
- How to store data using tuples.
- How to work with sets and unique values.
- How to create and access dictionaries.
- How to use nested dictionaries.
- How to identify data types using `type()`.
- How to perform basic calculations.
- How to organize related information using Python data structures.

## 3. Project Requirements

The program should:

1. Collect the names of three students.
2. Collect their roll numbers.
3. Collect their marks.
4. Store student names in a list.
5. Store roll numbers in a tuple.
6. Store marks in a set.
7. Store complete student records in a dictionary.
8. Calculate total marks.
9. Calculate average marks.
10. Display the data types of the data structures.
11. Display the organized student records.

**Important:** Complete this project without conditional statements or loops.

## 4. Data Structures Used

| Data Structure | Purpose |
|---|---|
| List | Stores student names |
| Tuple | Stores roll numbers |
| Set | Stores unique student marks |
| Dictionary | Stores complete student records |

## 7. Concepts Used

### Lists
Lists store multiple student names in a single variable.

### Tuples
Tuples store multiple roll numbers in an ordered collection.

### Sets
Sets store unique marks and automatically remove duplicate values.

### Dictionaries
Dictionaries store information using key-value pairs.

### Nested Dictionaries
A dictionary inside another dictionary helps organize related student details.

### Type Function
The `type()` function identifies the data structure used.

### Arithmetic Operations
Addition and division are used to calculate total and average marks.
