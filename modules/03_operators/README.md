# Module 03 -- Operators and Expressions

Operators perform operations on values.

## Arithmetic

``` python
a = 10
b = 3
print(a + b)   # 13
print(a - b)   # 7
print(a * b)   # 30
print(a / b)   # 3.333...
print(a // b)  # 3, floor division
print(a % b)   # 1, remainder
print(a ** b)  # 1000, power
```

## Comparison

Comparison operators return `True` or `False`: `==`, `!=`, `>`, `<`,
`>=`, `<=`.

``` python
print(10 > 5)   # True
print(10 == 5)  # False
```

## Logical operators

`and` means both conditions must be true; `or` means at least one; `not`
reverses the result.

``` python
age = 22
has_id = True
print(age >= 18 and has_id)  # True
```
