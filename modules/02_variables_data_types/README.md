# Module 02 -- Variables and Data Types

## Variables

A variable is a name that refers to a value.

``` python
name = "Anu"
age = 20
print(name, age)
```

## Common data types

  Type        Meaning          Example
  ----------- ---------------- -----------------
  `int`       Whole number     `age = 20`
  `float`     Decimal number   `price = 12.5`
  `str`       Text             `name = "Anu"`
  `bool`      True or False    `passed = True`
  `complex`   Complex number   `z = 2 + 3j`

Check a value's type with `type()`.

``` python
print(type(age))
```

Use meaningful variable names, such as `student_name`. Names cannot
start with a number or be Python keywords.
