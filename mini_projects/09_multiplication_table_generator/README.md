
# Mini Project 09: Multiplication Table Generator

## Project Overview

The Multiplication Table Generator is a beginner-friendly Python project that generates multiplication tables based on user input.

The user can enter a number, choose the starting and ending multipliers, and view the multiplication table.

The program also calculates the sum of all multiplication results and allows the user to generate multiple tables without restarting the program.

## Objectives

- Understand the use of for loops.
- Understand the use of while loops.
- Generate multiplication tables dynamically.
- Use variables to store and update values.
- Perform basic mathematical calculations.

## Requirements

- Python 3.x
- Any Python code editor (VS Code recommended)

## How to Run

1. Open the project folder in VS Code.
2. Open the terminal.
3. Run the following command:

```bash
python main.py
```

## Sample Input

```text
Enter the number: 5
Enter the starting multiplier: 1
Enter the ending multiplier: 5
```

## Sample Output

```text
Multiplication Table
-----------------------------
5 x 1 = 5
5 x 2 = 10
5 x 3 = 15
5 x 4 = 20
5 x 5 = 25
-----------------------------
Total of all results: 75
```

## Concepts Used

### 1. While Loop

The while loop allows the user to generate multiple multiplication tables until they choose to stop.

### 2. For Loop

The for loop generates the multiplication table from the starting multiplier to the ending multiplier.

### 3. Range Function

The range() function controls the sequence of multipliers.

### 4. Accumulator

The total variable stores the sum of all multiplication results.

### 5. User Input

The input() function collects values from the user.
