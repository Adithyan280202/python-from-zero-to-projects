
# Personal Expense Tracker

## Project Overview

The Personal Expense Tracker is a beginner-friendly Python application that helps users record and manage their daily expenses.

Users can add expenses, view recorded expenses, and calculate their total spending through a simple menu-driven interface.

## Features

- Add new expenses.
- View all recorded expenses.
- Calculate total expenses.
- Categorize expenses.
- Simple menu-driven interface.

## Requirements

- Python 3.x
- VS Code or any Python code editor.

## How to Run

1. Open the project folder in VS Code.
2. Open the terminal.
3. Execute:

```bash
python main.py
```

## Sample Input

```text
Enter your choice: 1
Enter expense name: Food
Enter category: Personal
Enter amount: 150
```

## Sample Output

```text
Expense added successfully!

Total Expenses: ₹ 150.0
```

## Current Limitations

- Expenses are stored only in memory.
- Data will be lost when the program is closed.
- No expense editing or deletion feature yet.

- Store data using JSON.

- Display category-wise spending.

## Learning Outcomes

After completing this project, users will understand how to:

- Store data using lists and dictionaries.
- Use loops and conditional statements.
- Build a menu-driven application.
- Perform calculations using stored records.
