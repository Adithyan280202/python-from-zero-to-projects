# 🐍 Python From Zero to Projects

### A Free, Beginner-Friendly Python Learning Resource

Welcome to **Python From Zero to Projects**!

This repository is designed to help anyone learn Python programming from the fundamentals to practical application development.

Whether you are a complete beginner or someone looking to strengthen your programming skills, this repository provides structured lessons, practical examples, coding exercises and hands-on projects.

Our learning philosophy:

**Learn → Understand → Practise → Build → Share**

---

## 🎯 Learning Objectives

By completing this learning programme, you will be able to:

- Understand Python programming fundamentals.
- Write clean and structured Python programs.
- Work with strings and data structures.
- Develop problem-solving and logical thinking skills.
- Handle files and exceptions.
- Understand object-oriented programming.
- Build real-world applications using Core Python.
- Manage and publish projects using Git and GitHub.

## 📚 Complete Python Curriculum

| No. | Module | Topics |
|---|---|---|
| 01 | Introduction to Python | Installation, setup and first program |
| 02 | Variables and Data Types | Variables, numbers, strings and booleans |
| 03 | Operators and Expressions | Arithmetic, comparison and logical operators |
| 04 | Input and Output | Input, output and type conversion |
| 05 | Strings | Indexing, slicing and string operations |
| 06 | Data Structures | Lists, tuples, sets and dictionaries |
| 07 | Conditional Statements | if, elif and else |
| 08 | Looping Statements | for, while and nested loops |
| 09 | Functions and Scope | Functions, arguments and return values |
| 10 | Recursion and Lambda | Recursive functions and lambda expressions |
| 11 | Modules and Packages | Imports and virtual environments |
| 12 | File Handling and JSON | Reading, writing and storing data |
| 13 | Exception Handling | Errors, exceptions and debugging |
| 14 | Object-Oriented Programming | Classes, objects and inheritance |
| 15 | Comprehensions and Iterators | Comprehensions, iterators and generators |
| 16 | Advanced Core Python | Decorators and advanced concepts |
| 17 | Git, GitHub and Testing | Version control and testing fundamentals |
| 18 | Practical Python Projects | Complete application development |
